## Privacy and access

Only app/build, predefined technical category/operation/surface, browser family/major version, platform, whitelisted exception type, own code-file name/line/column, HTTP status, bounded duration and random trace/span IDs are retained. No message text, exception message, raw stack, full URL/query/fragment, request/response body, headers, password/token, form field, account/dog name/ID, photo, cookie, full user agent, IP address or session replay is stored in diagnostics. Existing platform access/auth logs are separate and are not changed by this feature. Transport still uses the app's normal authenticated Supabase header, never stores that token in a trace.

A custom exporter serializes whitelisted fields into OTLP JSON and sends it to portal_telemetry_ingest_v345 through the existing authenticated Supabase REST RPC transport. It is not a general-purpose public OTLP collector endpoint. The server authenticates a live auth.sessions session and active/unblocked customer or staff, prevents customer app='admin' spoofing, validates payload shape/size/batch, revalidates every retained field, and discards arbitrary OTLP fields. A private table stores flattened columns, never raw payload. Unique trace/span IDs deduplicate retries. Anonymous and customer direct reads are denied; portal_staff_telemetry_v345 is active-staff/session-only and returns bounded seven-day aggregates (max100groups). All new function grants are explicit; private tables have RLS and no anon/authenticated direct grants.

Per-user daily-salted hashes are retained only in a private rate-limit table for one day, without raw user ID/IP;60spans/10minutes/user and5000spans/day globally. Events are removed after30days by an hourly pg_cron cleanup; stale budgets are also deleted. No new provider receives customer diagnostics. No marketing/AI-traffic statistics or business records are changed. The code-level whitelist and database permissions must stay authoritative in future instrumentation. Do not add recordException(error), console recording, URL/query capture, form capture or SDK auto-instrumentation without a new privacy review.
