## Scope and material

Replace PR177's entire experimental v2 block, its inverse-map adapter and unused vendor. No added override stack. Existing layout, photo nodes, gender photo borders, background paw artwork/300×430 tile/origin and motion are preserved. Wallpaper colour becomes light peach `#ffd0ae`; gender panel fill becomes pink `rgba(245,154,201,.62)` or blue `rgba(135,190,240,.62)`. An inert optical span sits behind the original sharp DOM. No hard white card border. A subtle inner sheen and soft shadow define the material. The dock outer container retains its original fixed position and existing horizontal centering transform: no filter or additional transform.

- Chromium: per-dimension LiquidLens Snell/SDF maps, radius/bezel calibrated for each surface; separate SVG backdrop layer. Refraction scale is twice the requested maximum displacement because the normalized channels decode as channel−0.5. At most10px edge displacement, identity interior,0.65px blur,115% saturation; no chromatic splitting. Map cache bounded to32 entries, resize driven; no map generation per animation frame.
- WebKit: Simple Liquid Glass WebGL on the dock and the first visible profile information panel only, maximum2 contexts. Other cards use3px CSS fallback. Low CPU/memory, reduced transparency or high contrast disable the GPU path. Context/capture failure retains readable fallback. Offscreen/hidden/backgrounded panels release resources; context teardown explicitly loses the old context.
- WebGL uses an explicit wallpaper-plus-profile-tint canvas, **not a capture of arbitrary page content**. This refracts the original paw detail and matching gender colour; the dock cannot refract arbitrary text/photos passing underneath. This is a deliberate preview limitation, not native iOS compositing or full cross-platform parity. No private customer content is rasterized. The original data-SVG with internal `use` tainted WebKit canvases (observed SecurityError); an exact300×430 Chromium raster of the same SVG is used only for the origin-clean GPU texture. The visible CSS paw source is unchanged. The canvas revision changes on geometry/scroll/tint changes; a small documented upstream adaptation skips idle texture uploads. No backend calls or polling. One same-origin static texture request only on WebKit.
